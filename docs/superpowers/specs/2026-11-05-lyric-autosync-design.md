# 가사 자동 맞춤 설계

작성일: 2026-11-05 / 상태: 검토 대기

## 목표

관리자가 STUDIO의 곡 편집 화면에 가사를 넣고 버튼을 누르면, 줄별 시간값이 자동으로 채워진다. 틀렸을 가능성이 높은 줄만 확인해 고치고 저장한다. 파일을 따로 만들 필요가 없다.

**성공 기준**
- 지금 시간값이 있는 8곡을 다시 맞췄을 때, 실제 브라우저에서 줄의 90% 이상이 1초 이내로 맞는다.
- 3~5분 곡 하나의 분석이 브라우저에서 10분 안에 끝난다. 두 번째 곡부터는 모델을 다시 받지 않는다.
- 사람이 고칠 줄이 화면에 표시되어, 곡 전체를 끝까지 듣지 않아도 검토할 수 있다.

## 시험에서 확인한 것 (2026-11-05)

Node 환경에서 Whisper small로 8곡 358줄을 시험했다. 브라우저에서는 측정하지 않았다.

| 항목 | 결과 |
|---|---|
| 오차 중앙값 | 0.12초 |
| 1초 이내 | 95% |
| 인식 일치율 30% 이상인 줄 | 99% 이상이 1초 이내 |
| 인식 일치율 30% 미만인 줄 (19줄) | 21%만 1초 이내 |
| 언어를 잘못 지정한 곡 | 거의 전부 틀림 |
| 처리 시간 | 곡당 30~65초 |

## 브라우저 측정 결과 (2026-11-06)

앱 내장 Chromium, WebGPU, 앱 창이 숨겨진 상태로 측정했다. 처리 시간에는 음원 다운로드가 포함되고, 모델은 이미 캐시된 상태다. 언어는 자동 판별했고 8곡 모두 맞았다.

| 곡 | 언어 | 1초 이내 | 2초 이내 | 확인 필요 표시 | 처리 시간 / 곡 길이 |
|---|---|---|---|---|---|
| Nel Vuoto, Ti Chiamo | 이탈리아어 | 87% | 89% | 6줄 | 342초 / 338초 |
| Rhodes & Whiskey | 한국어 | 88% | 88% | 2줄 | 215초 / 199초 |
| 닮아가는 밤 | 한국어 | 93% | 96% | 2줄 | 272초 / 336초 |
| それでも夜は明ける | 일본어 | 84% | 94% | 3줄 | 412초 / 295초 |
| La Ville Écoute | 프랑스어 | 100% | 100% | 0줄 | 233초 / 277초 |
| 냉장고 로맨스 | 한국어 | 100% | 100% | 0줄 | 287초 / 234초 |
| まだ灯りのある部屋 | 일본어 | 90% | 93% | 2줄 | 310초 / 315초 |
| Crown of Noise | 한국어 | 94% | 95% | 6줄 | 330초 / 285초 |
| **전체 358줄** | | **93%** | **95%** | 21줄 | 최대 412초 |

**측정으로 추가된 규칙:** 다른 문자로 된 괄호 줄은 번역으로 보고 언어 판별과 맞춤에서 제외하되, 저장 시 윗줄 아래에 그대로 둔다. `(Instrumental)`, `(피아노 숨)` 같은 연주 표시도 맞춤에서 뺀다.

## 범위

**포함:** 줄 단위 시간 맞춤, 언어 판별, 검토 화면, 수동 탭 맞춤.

**제외:** 단어별 노래방 표시, 여러 곡 일괄 처리, 서버 또는 유료 API 사용, 보컬 분리 AI, 재생 화면 변경. 재생 화면은 이미 `[mm:ss.xx] 가사` 형식을 읽는다.

Firestore 구조, 보안 규칙, 서버 함수는 바꾸지 않는다. 결과는 기존 `lyrics` 문자열에 저장한다.

## 흐름

1. 곡 편집 화면의 가사 입력칸 아래 **자동 맞춤** 버튼을 누른다. 음원 주소와 가사가 있어야 한다.
2. 언어를 판별해 보여 준다. 잘못되었으면 바꿀 수 있다.
3. 모델과 음원을 받아 분석한다. 단계별 진행 상황과 취소 버튼을 보여 준다.
4. 검토 화면에서 줄별 시간과 "확인 필요" 표시를 본다. 줄을 들어 보고 고친다.
5. **적용**을 누르면 편집 중인 가사 입력칸에 시간값이 들어간다. 기존 **저장**을 눌러야 저장되며, 이전 내용은 변경 이력에 남는다.

## 언어 처리

언어는 입력한 가사를 기준으로 정한다. 시험에서 정확도를 가장 크게 좌우한 요소다.

- 곡에 `language` 값이 있으면 그 값을 먼저 쓴다.
- 한글이 가장 많으면 한국어, 가나가 있으면 일본어로 정한다.
- 라틴 문자 가사는 글자만으로 구분할 수 없어 자주 쓰는 단어로 영어, 프랑스어, 이탈리아어, 스페인어를 추정한다. 판별이 애매하면 관리자에게 고르게 한다.
- 언어가 섞인 곡은 가장 많은 언어로 분석한다. 다른 언어 줄은 일치율이 낮아 "확인 필요"로 표시될 수 있다.

## 구성

| 파일 | 역할 |
|---|---|
| `src/utils/lyricAlign.js` | 가사 파싱, LRC 변환, 언어 판별, 문자 정렬, 시간 추정. 외부 의존성 없는 순수 함수 |
| `src/workers/lyricSync.worker.js` | Whisper 실행. UI가 멈추지 않도록 Web Worker에서 동작 |
| `src/utils/lyricAudio.js` | 음원을 받아 16kHz 모노로 바꾸고 보컬 대역(200Hz~3.8kHz) 필터 적용 |
| `src/components/admin/LyricSyncPanel.jsx` | 진행 상황, 검토, 수동 탭 화면 |
| `src/components/admin/TrackManager.jsx` | 버튼을 추가하고 패널을 지연 로딩 |

**모델:** `onnx-community/whisper-small_timestamped` q8 (약 240MB). 브라우저 캐시에 저장한다. WebGPU를 먼저 쓰고, 안 되면 WASM을 쓴다. `@huggingface/transformers`는 버튼을 누를 때만 불러오므로 방문자 번들에 포함되지 않는다.

**정렬:** 인식 결과와 입력 가사를 문자 단위로 전역 정렬한다. 줄의 시간은 처음 일치한 문자에서 구한다. 일치율 30% 미만인 줄은 앞뒤 신뢰 줄 사이를 보간하고 "확인 필요"로 표시한다.

**입력 정리:** 기존 시간값은 지우고 분석한다. `[Verse 1]` 같은 구간 표시는 분석에서 제외하고, 재생 화면이 시간값 없는 줄을 표시하지 않으므로 결과에도 넣지 않는다.

## 검토 화면

- 줄마다 시간, 가사, "확인 필요" 표시, 듣기 버튼, ±0.1초 버튼을 둔다.
- "확인 필요" 줄로 바로 이동할 수 있다.
- **탭 모드:** 곡을 재생하다 스페이스를 누르면 현재 줄에 시간을 찍고 다음 줄로 넘어간다. 시간이 항상 늘어나도록 앞뒤 줄 순서를 검사한다.
- 기존 시간값이 있는 곡은 덮어쓰기 전에 확인을 받는다.

## 오류 처리

| 상황 | 동작 |
|---|---|
| 음원을 브라우저에서 못 받음 (CORS 등) | 음원 파일을 직접 선택하게 한다 |
| 전체 일치율 40% 미만 | 언어를 확인하게 하고, 다른 언어로 재시도 또는 탭 모드를 안내한다 |
| 모델 다운로드 실패, 메모리 부족 | 원인을 알리고 탭 모드를 안내한다. 입력 가사는 유지한다 |
| 분석 중 취소, 페이지 이탈 | Worker를 종료한다. 입력 가사는 바뀌지 않는다 |
| 가사가 없거나 곡이 연주곡 | 버튼을 누를 수 없게 하고 이유를 표시한다 |

## 보안과 배포

- 모델 파일 주소(`huggingface.co`, `cdn-lfs*.huggingface.co` 등)를 report-only CSP의 `connect-src`에 추가한다. WASM 실행 파일은 프로젝트에서 직접 제공해 외부 스크립트를 늘리지 않는다.
- 분석은 관리자 브라우저 안에서만 이루어지며, 음원과 가사를 외부로 보내지 않는다.

## 테스트

- **단위 테스트:** 정렬, 언어 판별, LRC 변환, 구간 표시 제외, 일치율 표시, 시간 순서 검사.
- **정확도 회귀 시험:** 8곡의 손으로 맞춘 시간과 비교하는 스크립트를 유지한다. 음원과 모델이 필요해 CI에서는 돌리지 않는다.
- **브라우저 검증:** 8곡을 실제 Chrome에서 돌려 성공 기준을 확인한다.

## 구현 순서

1. 정렬 모듈과 단위 테스트.
2. **브라우저 측정:** Worker와 음원 처리를 먼저 만들어 Chrome에서 속도와 정확도를 잰다. 기준에 못 미치면 모델 크기와 방식을 다시 정한다.
3. 수동 탭을 포함한 검토 화면.
4. STUDIO 연결, 시간값 없는 5곡으로 실제 사용 확인.

## 남은 위험

- 시험 표본이 8곡이고, 정렬 기준도 이 8곡으로 확인했다. 새 곡에서는 정확도가 다를 수 있다.
- 메모리 사용량은 측정하지 않았다. 메모리가 적은 기기나 WebGPU가 없는 브라우저에서는 더 느리거나 실패할 수 있다.
- 언어가 섞인 곡은 시험하지 못했다.
